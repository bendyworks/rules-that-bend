# The GitHub CLI commands this project names: the ones its tools run and
# the ones its skills and guidance give a session, one per line. A
# `gh`-compatible tool for another host would have to answer them, and
# it would run with the user's credentials, so it has to be one the
# team trusts. CONTRIBUTING.md ("GitHub is required") says why the list
# exists. test/gh_calls_test.rb compares it in both directions with the
# commands named under skills/, guidance/, and bin/, and with the calls
# each tool declares, so add a line when a change names a new command
# and remove one when the last use goes.
#
